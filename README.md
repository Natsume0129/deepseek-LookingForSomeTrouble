# 小鲸鱼的新鲜事 · Looking for Trouble

一个 AstrBot 主动分享插件：读取选定的 RSS 信源，结合兴趣偏好与当前人设挑选内容，随机私聊给配置的接收者。

插件标识为 `astrbot_plugin_whale_discovery`，当前版本为 **1.1.0**。

源码仓库：[Natsume0129/deepseek-LookingForSomeTrouble](https://github.com/Natsume0129/deepseek-LookingForSomeTrouble)。尚未提交 AstrBot 插件市场收录。

## 功能

- 预置信源可多选；用自然语言配置兴趣和排除话题。
- 每天在上下限之间随机抽取分享机会数，再随机安排在允许的时间段内。
- 支持多段时间、跨午夜时间段、静默时段、时区和发送间隔。
- 所有接收者共享每日上限，同一内容不会再发给其他人。
- 把文章与实际配图交给模型筛选，美食必须有配图并通过食欲评分。
- 消息附来源链接，使用原文配图，**不是网页截图**。
- SQLite 保存计划和发送记录；重载不会重新抽签，发送状态不明时不重试。
- 在接收者之后的模型对话中补充最近两条已确认分享，便于继续聊；不会把另一位接收者的分享注入当前会话。

## 运行条件

- AstrBot **4.29.0 或更高**；本地初版在 4.29.3 上运行验证，未验证所有后续版本。
- Python **3.12 或更高**，依赖见 `requirements.txt`。
- 已配置可用的聊天模型与人设。推荐支持图片输入、能可靠输出 JSON 的模型；图片文章会发送图片给模型评估。
- 当前只支持 `机器人ID:FriendMessage:用户ID` 格式的私聊，已在 QQ OneBot v11 环境验证；不宣称支持其他平台的会话格式。
- 需要网络访问选定信源和模型服务，模型调用按供应商规则计费。无需额外的新闻 API Key。
- AstrBot 和消息适配器需要持续运行。本插件不启动 QQ、不处理登录过期、不安装 Ollama，也不依赖记忆插件。

## 安装

在 AstrBot 后台「插件 → 安装插件 → 从链接安装」填写：

```text
https://github.com/Natsume0129/deepseek-LookingForSomeTrouble
```

也可以将以下文件放在 ZIP 根目录，在「插件 → 安装插件 → 上传文件」安装：

```text
main.py
engine.py
metadata.yaml
_conf_schema.json
requirements.txt
LICENSE
README.md
```

也可以把本目录放到 AstrBot 的 `data/plugins/astrbot_plugin_whale_discovery`，然后重载插件。

安装后默认关闭，接收者列表为空，不会自动向任何人发消息。

## 配置

在后台「插件 → 小鲸鱼的新鲜事 → 配置」设置以下选项，然后保存并重载插件。

| 配置项 | 用途 | 默认值 |
| --- | --- | --- |
| `enabled` | 启用定时分享 | `false` |
| `recipients` | 随机选择的私聊会话列表 | 空 |
| `sources` | 预置信源 ID，可多选 | 全部四个 |
| `interests` | 用自然语言描述兴趣 | 趣闻、动物、自然、美食等 |
| `avoid_topics` | 不希望主动分享的话题 | 股价、营销、灾难等 |
| `sharing_windows` | 可分享时间段 | `10:00-13:00`、`16:00-19:00`、`21:00-23:50` |
| `daily_min` / `daily_max` | 每天随机分享机会数范围 | `1` / `3` |
| `min_interval_minutes` | 两次发送最小间隔 | `180` 分钟 |
| `timezone` | IANA 时区 | `Asia/Shanghai` |
| `quiet_start` / `quiet_end` | 静默时段 | `03:00` / `09:30` |

接收会话的格式示例为 `my_bot:FriendMessage:用户QQ号`，其中 `my_bot` 必须是你在 AstrBot 中配置的机器人 ID，而非插件名称。**同时启用 AstrBot 白名单并加入该完整会话 ID**，否则插件不会向其发送。移除接收者或白名单条目即可停止向该账号分享。

次数范围支持 `0 <= daily_min <= daily_max <= 24`。例如 `1–3` 为随机次数，`3–3` 为每天固定三个机会，`0–0` 为不安排分享。每日上限是所有接收者合计，不是每人分别计算。

时间格式为 `HH:MM-HH:MM`，例如 `22:00-02:00` 支持跨午夜。开始包含、结束不包含；跨午夜窗口按每个自然日的两段时间计算，不把凌晨额度记在前一天。静默时段优先，起止相同表示全天静默。允许时间段清空后不分享。

实际发送可能少于抽取次数：内容不够好、信源不可访问、时间段不足、间隔冲突、错过机会或发送失败都会少发。插件不会为了凑次数硬发，错过超过一小时的机会不会补发。

每日计划会持久化。修改时间或次数后，既有计划不会重新随机生成；新增的计划在下一天生效。开关、接收人、白名单、发送上限、时间段和静默限制在重载后立即约束发送，因此收紧限制可以阻止既有计划，但放宽限制不会额外补出机会。

## 可选信源

| 配置 ID | 来源 | 内容 |
| --- | --- | --- |
| `justonecookbook` | [Just One Cookbook](https://www.justonecookbook.com/feed/) | 日式料理、甜点、美食 |
| `solidot` | [Solidot](https://www.solidot.org/index.rss) | 科技、科学、互联网趣闻 |
| `ithome` | [IT之家](https://www.ithome.com/rss/) | 数码、游戏、新奇产品 |
| `nasa` | [NASA](https://www.nasa.gov/feed/) | 太空、天文、自然图片 |

例如，信源只选 `justonecookbook`、`nasa`，兴趣填写「看着好吃的甜点、漂亮的星云照片」，就会在这两个源中筛选。兴趣配置不是全网搜索，也不会新增信源。

目前仅提供上述预设，不开放任意 URL；抓取及重定向限制在这些站点的域名范围内。站点更新、网络限制和外域图床可能导致文章或图片被跳过。非美食可在没有配图时只发文字；美食没有可读配图就跳过。

## 状态、数据和隐私

管理员发送 `/新鲜事状态` 可查看时区、计划、已使用次数和当前设置。

运行数据位于 AstrBot 的 `data/plugin_data/astrbot_plugin_whale_discovery/`：

- `state.db`：每日计划、接收会话、链接、消息和发送结果。
- `*.jpg`：用于筛选和发送的文章配图。

不要把运行数据提交到公开仓库。当前版本未做缓存自动清理；长期使用需关注磁盘空间。卸载前可备份整个插件数据目录，删除状态库会失去去重和限额历史。

文章、配图、当前人设和接收者 ID 会发送给所配置的模型供应商，用于生成分享。插件不会读取密钥文件或向信源发送聊天内容，模型访问使用 AstrBot 已有的提供商配置。外部页面只作为资料，不授予工具权限。

模型筛选和事实判断可能出错；来源链接用于核实。转载配图的权利属于原权利人，代码许可证不授予第三方文章、图片的使用许可。

## 开发与验证

```sh
python -m pip install -r requirements.txt
python -m unittest test_engine -v
```

测试使用虚构 ID、临时数据库和模拟发送，不连接 QQ，不调用付费模型。覆盖静默边界、次数上限、持久化去重、跨午夜窗口、预设源选择和兴趣传递。原版做过在线内容预览；这个整理版尚未作为公开版本进行长时间运行验证。
