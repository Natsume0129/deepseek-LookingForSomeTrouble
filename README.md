# 小鲸鱼的新鲜事 · Looking for Trouble

让你的 AstrBot 偶尔带着新鲜事来找你聊天。

插件从 RSS 信源中寻找有趣的文章、图片和美食，按照你设置的兴趣筛选，再用机器人当前的人设写几句感想，附上配图和原文链接，主动发到私聊。

## 功能

- **按兴趣挑内容**：可选择信源，用自然语言描述喜欢和不喜欢的话题。
- **沿用当前人设**：用机器人的说话风格分享，并在后续聊天中保留最近两条分享作为上下文。
- **随机时间、随机接收者**：每天随机安排分享机会，每次从接收者列表中选一人。
- **控制打扰频率**：支持每日次数范围、多个分享时间段、最小间隔和静默时段。
- **图文分享**：使用文章原图并附来源链接；美食会结合图片筛选看起来好吃的内容。
- **自动去重**：保存分享记录，同一条内容不会重复发送给其他接收者。

## 安装

需要 AstrBot **4.29.0+**、Python **3.12+**，以及已连接的 QQ OneBot v11 机器人。先在 AstrBot 中配置聊天模型和人设，模型应支持图片输入和 JSON 输出。

在 AstrBot 后台打开「插件 → 安装插件 → 从链接安装」，填入：

```text
https://github.com/Natsume0129/deepseek-LookingForSomeTrouble
```

插件使用 AstrBot 已有的模型配置。内容筛选和文案生成会消耗模型 API 用量。

## 开始使用

1. 打开「插件 → 小鲸鱼的新鲜事 → 配置」。
2. 添加接收者，格式为 `机器人ID:FriendMessage:用户QQ号`。例如机器人 ID 为 `my_bot`，就填写 `my_bot:FriendMessage:用户QQ号`。
3. 在 AstrBot 的「配置文件 → 访问控制 → 白名单」中启用白名单，并添加同一条完整会话 ID。
4. 选择信源，填写兴趣偏好，设置分享时间和次数。
5. 打开「启用定时分享」，保存配置并重载插件。

保持 AstrBot 和 QQ 连接在线，插件就会在计划时间自动筛选并分享内容。

管理员可以发送以下指令查看当天计划和使用次数：

```text
/新鲜事状态
```

## 选择信源

| 配置 ID | 来源 | 内容 |
| --- | --- | --- |
| `justonecookbook` | [Just One Cookbook](https://www.justonecookbook.com/feed/) | 日式料理、甜点、美食 |
| `solidot` | [Solidot](https://www.solidot.org/index.rss) | 科技、科学、互联网趣闻 |
| `ithome` | [IT之家](https://www.ithome.com/rss/) | 数码、游戏、新奇产品 |
| `nasa` | [NASA](https://www.nasa.gov/feed/) | 太空、天文、自然图片 |

可以同时选择多个信源。兴趣偏好用于筛选这些来源中的内容，例如：

> 喜欢可爱动物、有趣的科学发现、新奇小游戏，还有看着就想吃的甜点和炸物。

排除话题可以填写：

> 不要股价、行业通稿、手机参数对比和营销广告。

## 配置说明

| 配置项 | 用途 | 默认值 |
| --- | --- | --- |
| `enabled` | 启用定时分享 | 关闭 |
| `recipients` | 随机私聊接收者列表 | 空，需自行填写 |
| `sources` | 选择信源 | 全部四个 |
| `interests` | 兴趣偏好 | 趣闻、动物、自然、美食等 |
| `avoid_topics` | 排除话题 | 股价、营销、灾难等 |
| `sharing_windows` | 允许分享的时间段 | `10:00-13:00`、`16:00-19:00`、`21:00-23:50` |
| `daily_min` / `daily_max` | 每日随机分享机会的最少、最多次数 | `1` / `3` |
| `min_interval_minutes` | 两次分享最小间隔 | `180` 分钟 |
| `timezone` | 时区 | `Asia/Shanghai` |
| `quiet_start` / `quiet_end` | 静默时段 | `03:00` / `09:30` |

### 分享次数

每日次数范围支持 `0–24`，最少次数不能大于最多次数。例如：

- `1–3`：每天随机安排一到三次分享机会。
- `3–3`：每天安排三次分享机会。
- `0–0`：停止安排分享。

**次数是所有接收者合计。** 没有找到合适内容时会跳过，所以实际发送次数可能少于计划次数。

### 分享时间

时间段使用 `HH:MM-HH:MM` 格式，可以填写多段，也支持 `22:00-02:00` 这样的跨午夜时段。静默时段优先于分享时间段；两次发送还需满足最小间隔。

按设置时区的自然日计算次数。开始时刻包含在内，结束时刻不包含；静默起止时间相同表示全天静默。时间段清空后停止分享。

当天计划会保存，重启后继续使用。修改配置并重载后，开关、接收者、次数上限和时间限制立即生效；随机计划在下一天重新生成。离线错过超过一小时的机会会跳过。

### 配置示例

下面这组设置会从美食和太空信源中挑选内容，每天安排一到三次分享，发送间隔至少两小时：

```json
{
  "sources": ["justonecookbook", "nasa"],
  "interests": "诱人的甜点、热腾腾的饭菜、漂亮的星云和自然奇观",
  "avoid_topics": "猎奇食物、营销广告",
  "sharing_windows": ["10:00-13:00", "18:00-23:00"],
  "daily_min": 1,
  "daily_max": 3,
  "min_interval_minutes": 120,
  "timezone": "Asia/Shanghai",
  "quiet_start": "23:00",
  "quiet_end": "09:30"
}
```

## 常见问题

**启用后为什么没有立刻发消息？**

插件按随机计划运行。发送 `/新鲜事状态` 查看时间，并确认接收者已加入白名单、QQ 在线、当前处于允许分享的时段。

**可以只分享某一类内容吗？**

可以。选择相应信源，再在兴趣偏好中写明主题。例如只选 `justonecookbook`，兴趣填「蛋糕、布丁和日式甜点」。

**为什么有时候只有文字？**

文章没有可读取的配图时，非美食内容可以只分享文字和来源。美食内容必须有图片并通过视觉筛选。

**怎样停止主动分享？**

关闭「启用定时分享」并重载插件。只想停止向某个人发送时，从接收者列表移除其会话即可。

## 数据与备份

插件数据保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_whale_discovery/`：

- `state.db`：每日计划、接收会话和分享记录。
- `*.jpg`：文章配图缓存，目前需手动清理。

迁移时备份整个目录，可保留计划、去重和次数记录。内容筛选会将文章、配图、当前人设和接收者 ID 交给 AstrBot 配置的模型处理。
